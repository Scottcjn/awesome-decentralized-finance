# Contributing to Awesome Decentralized Finance

Thanks for helping keep this decentralized finance resource list useful and current. Contributions should make it easier for readers to discover well-documented DeFi protocols, tools, analytics, and learning resources.

## What to Add

- Open source DeFi protocols, developer tools, dashboards, analytics, documentation, and educational resources.
- Projects with a live website or documentation page and a stable public source, governance, or reference link.
- Entries that fit an existing section such as decentralized exchanges, stablecoins, lending, staking, yield, derivatives, layer 2s, asset management, applications, analytics, or community.

## Entry Format

Use the existing list style:

```markdown
- [Project Name](https://example.com) ([source code](https://github.com/org/repo), [docs](https://docs.example.com/)) - Short factual description
```

Keep descriptions concise and neutral. Mention the chain, category, or primary use case when it helps readers compare similar resources.

## Pull Request Checklist

- Place the entry in the most specific matching section.
- Keep entries alphabetized or grouped consistently with nearby entries when possible.
- Verify every added link resolves and points to the intended project.
- Avoid referral links, marketing language, price predictions, and unverifiable claims.
- Use plain Markdown and keep line wrapping consistent with nearby entries.

## Good Contributions

- Add missing documentation or source links for an existing project.
- Move an entry to a better section when the category is incorrect.
- Remove or update projects that are defunct, renamed, or now point to stale resources.
- Add a short historical note when a resource is important but no longer active.

## Not a Fit

- Token promotion, airdrop farming, referral campaigns, or price speculation.
- Anonymous projects without enough public documentation for readers to evaluate them.
- Duplicate entries already covered elsewhere in the list.
