# Contributing to Awesome Decentralized Finance

Thanks for helping curate the definitive DeFi resource list!

## Quick Start

1. Fork this repository
2. Add your project to the appropriate category
3. Open a Pull Request

## Adding a Project

### Format

```markdown
- [Project Name](https://link) ([source code](https://github.com/link), [docs](https://docs.link)) - One-line description
```

Include links to:
- Main website
- Source code (GitHub/GitLab)
- Documentation

## Categories

- **Decentralized Exchange Protocols** - DEXs, AMMs, aggregators
- **Stablecoins** - Fiat-backed, crypto-backed, algorithmic
- **Lending Protocols** - Borrowing/lending platforms
- **Liquid Staking** - Staking derivatives
- **Yield Aggregators** - Yield optimizers
- **Restaking Protocols** - EigenLayer, etc.
- **Derivative Protocols** - Prediction markets, options
- **Layer 2 Scaling** - Rollups, sidechains
- **Asset Management** - DAOs, vaults
- **Analytics** - Dashboards, tools

## Quality Criteria

**Accepted:**
- ✅ Decentralized finance protocol or tool
- ✅ Active development or significant TVL
- ✅ Open source or well-documented

**Not accepted:**
- ❌ Centralized exchanges
- ❌ Vaporware without mainnet
- ❌ Scam/rugpull projects

## Pull Request Checklist

- [ ] Project is DeFi-related
- [ ] Added to correct category
- [ ] Includes website, source, and docs links
- [ ] Description is concise
- [ ] Alphabetically sorted within section

## Updates

You can also:
- Update TVL/statistics
- Add new chains/networks
- Fix broken links
